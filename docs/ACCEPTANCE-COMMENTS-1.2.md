# 无我音乐 1.2.0 评论界面精简

2026-11-07，作者 LHL。最新运行目录：`release/无我音乐-1.2.0-评论优化/win-unpacked`，保留此前播放加载修复。

- 歌词左侧评论使用一行工具栏：热门、最新、自动滚动、关闭。移除该区域重复的歌曲名称、歌手、收藏／下载／MV 操作，以及“歌曲评论”标题和图标。歌曲与常用操作仍可在底部播放器和歌曲列表使用；关闭评论恢复封面及原有操作。
- 分类使用中性底色的紧凑按钮，自动滚动和关闭使用弱化图标；不再堆叠两层标题、两排操作和分隔线。
- 评论滚动条采用 5px 透明轨道和随主题变化的柔和滑块，移除原生上下箭头和白色轨道。仅作用于评论内容区域。
- 歌词页开启自动滚动时，所有已加载及后续加载的评论都显示全文，不显示逐条“展开／收起”按钮。自动展开不再被误判为手动阅读暂停；鼠标悬停、焦点进入内容、暂停播放或窗口隐藏时仍停止滚动。关闭自动滚动后恢复手动展开，手动展开状态保留。
- 保留热门／最新切换、连续向下加载、末尾循环、离线和错误重试处理；不新增计数或顶部说明文字。独立评论抽屉保留歌曲身份信息。

## 验证

`npm run build` 通过，`npm test` **73/73** 通过，日志见 `evidence/tests-comments-refinement-120.txt`。没有变更网络、下载或音频引擎；既有播放和下载回归均包含在本次测试中。

通过 cua-driver 检查真实打包程序与真实《牵丝戏》评论：

- 初轮小窗口检查了单行工具栏和自动展开，后续移除了滚动条残留的原生箭头。
- 最终运行副本在深色、浅色下检查工具栏、透明轨道、无箭头细滑块与完整长文。证据：`evidence/comments-refined-dark-120.png`、`evidence/comments-refined-light-120.png`。
- 自动滚动时真实长文完整显示并向下移动，期间继续加载后续评论。关闭自动滚动后，有限范围的 UIA 检查找到了 12 个“展开全文”按钮；重新开启后同一查询没有展开按钮。见 `evidence/comments-refined-gui-120.json`。
- 关闭评论后恢复唱片封面，确认“切换方形封面”操作重新出现。

GUI 使用与交付目录逐文件校验相同的 C 盘运行副本，沿用此前记录的 D 盘自动化启动限制。最终源码在首轮之后仅补充了设置说明和滚动条样式；最终副本重新检查了两种主题与自动展开切换。
