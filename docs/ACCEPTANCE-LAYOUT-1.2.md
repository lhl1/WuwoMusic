# 无我音乐 1.2.0 布局补充验收

2026-11-07，作者 LHL。本轮最新交付为 `release/无我音乐-1.2.0/win-unpacked`。旧目录被残留进程占用，Windows 拒绝重命名，完整保留旧目录并交付新的独立运行目录，没有强制终止进程。

## 本轮调整

- 播放器右侧加入 HiFi 输出入口，可切换标准／HiFi 独占，与设置页共用实际输出设置。HiFi 按钮开启后保持透明中性背景，不使用黄色填充，也不显示下拉箭头；菜单采用短文案并预留勾选空间，避免换行。
- 设置页统一为说明、控件两列；设备选择与刷新按钮在同一行并右侧对齐。窄窗口允许分行，长设备名称省略并保留完整悬浮提示。
- 下载管理采用与本地音乐一致的列表：序号、封面、歌曲、歌手、音质、状态、操作。窄窗口收起独立歌手列，在歌名下显示歌手；保留真实进度、速度、错误及暂停／继续／重试／播放／定位文件功能。
- 顶部新增连续 18px 拖动区域，顶栏空白、品牌区可拖动；搜索框及窗口按钮保持可交互。
- 删除推荐页的黄色“音乐，刚刚好”横幅。
- 顶栏和内容区建立独立层级，搜索联想始终覆盖封面与悬浮效果；输入和空白联想仍使用 APK 实际接口。
