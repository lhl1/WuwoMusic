# 2026-11-08 播放页布局、动效与静音

## 调整

- 覆盖播放页补回上一版 player-main 的外层间距：常规 6px 30px 24px，小窗口 5px 17px 18px。保留现有封面/评论模块比例，左侧不再贴边。
- 打开/收起使用 cubic-bezier(.16,1,.3,1) 非线性曲线，收起 260ms，从第一帧快速运动，再平滑减速，无起步延迟。以 animationend 完成收起，300ms 定时器仅为兜底；减少动态效果时动画约 0ms 并立即结束。不声称复制 iOS 私有动画实现。
- 扬声器改为可聚焦按钮，具有静音/取消静音标签和按下状态。静音与音量分开保存，取消静音不改音量；普通音量滑块调整会取消静音。小窗口更多菜单同样可切换。
- 标准音频使用 HTMLMediaElement.muted，MV 使用 video.muted，HiFi 使用 mpv 的 mute 属性；HiFi 软件音量仍固定 100%。新 mpv 启动时传入静音状态，加载前再次同步，防止已静音状态下切歌漏声。
