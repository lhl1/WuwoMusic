# 无我音乐 1.2.3 · 桌面交互与资料管理

作者 LHL。仅交付 Windows x64 的 `win-unpacked` 运行目录；源码与说明同步 GitHub。本轮在开始修改前备份 1.2.2 源码、运行目录和正式资料，测试使用独立资料目录。

## 实现与使用

- 搜索行增加 VIP、原唱、DTS:X 等细边框小标。VIP 来自 `fpay=1`，原唱来自 APK 搜索解析的 `originalsongtype=1`，DTS:X 沿用真实格式标记。没有字段时不猜测；标记不阻止播放、下载，也不冒充解码输出参数。歌曲副标题按实际返回展示。
- 歌词搜索修正为 APK 的 `lrccontent`、`newsearch=1`、`searchapi=11` 及已验证客户端参数。结果显示返回的 `lrc` 片段并强调匹配文字；服务 HTML 被转为文本，不注入页面。
- 歌手页提供单曲、专辑、视频、了解 TA。`artistinfo` 返回简介和资料，`artist2music` 返回歌曲，`albumlist` 返回专辑；视频采用 APK 的 `mobi.s?type=music_list&key=mv` XML 链路。视频按歌手编号过滤，使用歌曲 rid 复用现有 MV 播放及下载；弃用会忽略歌手条件的 artist2mv 搜索方式。支持分页、进入专辑及返回时恢复栏目、页码和浏览位置。
- 音量浮层使用竖向滑块和百分比，平时隐藏，悬停／聚焦时打开，离开后收起，Esc 可关闭。图标继续支持静音，调整音量取消静音；HiFi 仍提示设备调音量。
- 标准播放暂停约 140ms 淡出后暂停，恢复约 180ms 淡入。用户音量独立保存；过渡操作携带序号，切歌、快速恢复或音量变更会取消旧过渡。HiFi 暂停／恢复也有短增益过渡，正常播放恢复到 100%；没有实现两首歌交叉淡化。
- 本地音乐支持文件／递归目录导入，读取真实音频元数据；同一文件按路径去重并保留原曲库标识、已有封面。可搜索名称、歌手、专辑、路径，按名称／歌手／专辑／时长排序，筛选无损、本地或失效文件，检查文件是否可访问、定位文件。
- 本地、我喜欢和自建歌单共用批量管理工具，可收藏、加入其他歌单、下载、从列表移除；磁盘文件保留。自建歌单支持创建、重命名、删除、批量上移／下移。重排要求选择原有顺序。
- JSON 备份保存曲目编号与本地路径，不保存临时播放地址；导入会重新检查本地音频。M3U8 只导出本地文件，支持 UTF-8 M3U／M3U8 导入，按播放列表目录解析相对路径，跳过网络地址、缺失和重复条目。侧栏导入按钮新建歌单，列表内导入按钮合并到当前列表。
- 歌单分类改为独立弹窗：分组导航、分类搜索、小尺寸选项，支持 Escape、焦点返回和 Tab 循环。修复专辑卡片封面对齐、长艺术家名称与日期排布。
- 侧栏选中项在悬停时保留黄色与清晰文字。扩大顶栏、侧栏空白、页面标题、专辑头部与底栏空白的窗口拖动区域，交互按钮和输入框保留点击行为。

## 验证

1. `npm test`：**99 项通过**，`npm run build` 通过；保留既有播放、下载、网络、评论测试。新增覆盖徽标字段、歌词参数与文本化、歌手视频过滤、XML 异常、专辑分页、批量重排、文件去重、JSON／M3U8 实际本地音频往返、无效条目、搜索排序、淡入淡出取消及 HiFi 稳态恢复。
2. 真实 Electron 45.2.3、直连：检查周杰伦搜索的 VIP／原唱标记，歌词“而我将爱你所爱的人间”返回如愿与片段；检查单曲、45 张专辑、436 条视频及歌手资料。实际数量以查询时间为准。专辑、视频和歌手封面均取得 HTTP 200 与实际图片字节。见 [接口记录](evidence/desktop123-electron.json)。
3. cua-driver 检查打包程序：搜索徽标和歌词片段、歌手专辑／视频／简介、本地文件导入与列表搜索、本地音频播放及暂停／恢复、创建歌单、批量加入、重命名、分类搜索与选择。最终包另检查浅色 150% 与深色 100%、音量浮层和数值、资料延续及缩放后的较窄布局。
4. 播放列表导入导出的文件格式与音频元数据往返由自动化测试验证；桌面检查覆盖导入与导出对话框。当前桌面自动化无法可靠替换保存对话框中的预填文件名，未将该次保存操作记为成功。窗口精确尺寸调整也遇到远程桌面 DPI 坐标不一致，未将该操作记为最小窗口尺寸实测。
5. 原生 HiFi 本轮枚举到“远程音频”，该端点拒绝 WASAPI 独占，应用返回明确错误。过渡与取消由命令测试验证；本轮未完成支持独占的实体 DAC 播放测试，也未宣称位完美。见 [设备记录](evidence/hifi-1.2.3.json)。
6. Windows 10 实测；Windows 11 未实测。测试为代表场景，不表示验证了整个曲库或所有外部播放器的 M3U8 兼容性。

## 复现

```powershell
npm ci
npm test
npm run build
npx electron-builder --win dir --x64
```

真实接口检查：

```powershell
npx esbuild scripts/verify-desktop123-electron.ts --bundle --platform=node --format=cjs --external:electron --outfile=artifacts/verify-desktop123.cjs
& node_modules/electron/dist/electron.exe artifacts/verify-desktop123.cjs --user-data-dir="$env:TEMP/Wuwo-123-check" --disable-gpu
```

硬件相关脚本 `scripts/verify-hifi123.ts` 使用测试目录内的本地 FLAC，需自行准备该文件并选择支持独占的设备；不需要修改正式资料。普通应用构建不依赖测试机的音频文件。

界面复现：搜索“周杰伦”，打开歌手并切换四个栏目；搜索一句歌词后选择“歌词”；本地音乐导入文件后搜索并选择歌曲，创建歌单、批量加入、重命名、导出 JSON，再从侧栏导入备份。对比导入前后曲目和顺序，并检查原音频仍在磁盘。
